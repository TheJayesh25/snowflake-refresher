# Snowflake Refresher

A hands-on relearning repository documenting my exploration of Snowflake as part of my Data Engineering learning trajectory.

This is **not a portfolio project**. It is a technical learning/reference repository containing SQL exercises, notes, and selected screenshots from hands-on practice.

## What I'm re-learning

- Snowflake architecture
- Databases and schemas
- Virtual warehouses
- Permanent, transient and temporary tables
- Views and view types
- Stages
- Data loading
- Time Travel and data retention
- Snowflake SQL
- Data warehouse concepts
- Snowflake features and capabilities

## Purpose

The goal is to rebuild enough hands-on understanding of Snowflake to be able to:

1. Use the platform confidently.
2. Understand how it fits into a modern Data Engineering stack.
3. Explain key concepts during technical interviews.
4. Apply the concepts independently in larger projects.

## Notes

The SQL in this repository is written while learning and practicing concepts. It is intentionally structured as a reference rather than a production-ready application.

The larger implementation of Snowflake will be demonstrated separately through end-to-end Data Engineering projects.
